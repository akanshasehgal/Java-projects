# Applets – historical note

The syllabus lists **Applets**. They are covered here as a concept only and are **not used** in ShopSphere, because:

- Browsers removed support for the Java plug-in (2015–2017), so applets can no longer run in a web page.
- The Applet API was deprecated in Java 9, marked for removal in Java 17, and removed from the JDK in Java 26 (JEP 504).

## What an applet was

A small Java program embedded in an HTML page and run by the browser's Java plug-in.

```java
import java.applet.Applet;
import java.awt.Graphics;

public class HelloApplet extends Applet {

    public void init()    { /* called once when loaded */ }
    public void start()   { /* called when the page becomes visible */ }
    public void paint(Graphics g) {
        g.drawString("Welcome to ShopSphere!", 20, 20);
    }
    public void stop()    { /* called when the page is hidden */ }
    public void destroy() { /* called before unloading */ }
}
```

```html
<applet code="HelloApplet.class" width="300" height="60"></applet>
```

## Applet life cycle

```
init()  ->  start()  ->  paint()  ->  stop()  ->  destroy()
              ^                         |
              +------- (page revisited) +
```

## What replaced applets in ShopSphere

| Applet use | Modern replacement used in this project |
|------------|----------------------------------------|
| Interactive UI inside the browser | HTML + CSS + JavaScript (Bootstrap) generated by JSP |
| Desktop-style Java UI | Swing application (`swing-admin` module) |
| Talking to the server | HTTP requests to Servlets |
